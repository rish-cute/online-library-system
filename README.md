# Online Library System

A modern and responsive Online Library System built using React, Vite, Redux Toolkit, React Router, and Tailwind CSS.

This application allows users to:

* Browse books by category
* Search books by title or author
* View detailed book information
* Add new books to the library
* Navigate through dynamic routes
* Handle invalid routes with a custom 404 page

---

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/rish-cute/online-library-system
```

### 2. Open the project folder

```bash
cd online-library-system
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

### 5. Open the local server link shown in terminal
